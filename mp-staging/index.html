Radio stick layout

Input device

Calibration detects which stick axis is throttle, yaw, pitch and roll, their full range and direction, then saves it in this browser. Throttle is read as absolute — it never springs back.

Xbox / PlayStation controller

Controller type
Controller layout Throttle

Game-controller sticks spring back to the middle, so by default the middle of the throttle stick is hover: push up to climb, pull down to drop. Auto-detect treats Xbox, PlayStation and other standard controllers as game controllers and keeps FPV radios (and anything you've calibrated) on absolute throttle.

Switches

Live stick check

Check: right stick up = throttle up (and it stays), right stick right = yaw right, left stick forward = nose down, left stick right = roll right (Mode 3).
